# ProcureGuard Project Plan

## Intended user
Finance and procurement teams reviewing vendor invoices before payment.

## Bottleneck
Reviewers manually compare invoices against purchase orders and company policy,
calculate variances, identify discrepancies, and decide whether human review is required.

## Goal
Reduce review time and missed discrepancies while keeping consequential decisions
under human control.

## Primary metric
Decision accuracy on a fixed synthetic evaluation set.

## Secondary metrics
- Runtime per case
- Estimated API cost
- Number and type of detected issues
